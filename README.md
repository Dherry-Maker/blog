# Derítson da Graça — Personal Blog

Personal blog and portfolio: software, AI, projects and the journey to becoming a software engineer.

Single-file static site (`index.html`, no build step). Edit the `CONFIG` object near the bottom of the file to change posts, projects, links and the contact email.

## Run locally
Open `index.html` in a browser.

## Deploy with GitHub Pages
Settings → Pages → Deploy from a branch → `main` / `(root)`.
